# Нейм-плейты: заметки

Поиск по сети дал мало конкретики по названным играм; пункты без ссылок — общеизвестные приёмы, не проверенные источником.

- Отложенная полоска («след» потерянного здоровья) — стандарт: вторая полоска позади основной, скорость и цвет настраиваются ([Godot shader](https://godotshaders.com/shader/health-bar/), [Fab: delayed bar](https://www.fab.com/listings/0ab7ee41-cdf5-4010-840f-0fd2e15c4742)); отдельные цвета для потери и прироста.
- Пиксельный образец: потерянная часть желтеет и сползает назад ([OpenGameArt netslash](https://opengameart.org/content/netslash-ui-stuff)).
- WoW (Plater/ElvUI): цвет полоски несёт смысл (угроза, враг/союзник); игроки просят цвет угрозы только на рамке, а заливку оставить под здоровье, и три зоны здоровья >70 / 30–70 / <30 ([Blizzard forum](https://us.forums.blizzard.com/en/wow/t/bfa-tidy-plates-help/163926)).
- Редкость в ARPG (Diablo 4, PoE): элита и редкие выделяются рамкой/цветом и значками под полоской; игроки хотят, чтобы они читались в толпе ([Fextralife D4](https://diablo4.wiki.fextralife.com/Elites), [Steam PoE2](https://steamcommunity.com/app/2694490/discussions/0/598514808890892900)).
- Ragnarok / MapleStory / Tibia (по памяти): тонкая полоска с чёрной рамкой 1 px, у Tibia — цвет по здоровью зелёный→жёлтый→красный; без анимации, читаемость за счёт контрастной рамки.
- Решения для нас: рамка 1 px + блик сверху/тень снизу; цвет заливки по типу, золотая рамка у элиты, череп и деления у босса; вспышка у края удара, след держится и «капает», дрожь при ударе >10 %, зелёный прирост с бликом, щит светлой насечкой поверх.

## Цифры урона

- Разделение по источнику и месту ([Neverwinter, Cryptic](https://forum.arcgames.com/Neverwinter/roletracker/jump/1266779)): исходящий урон — в узкой зоне сбоку над целью, входящий по герою — справа-снизу от него, лечение и щиты — слева-снизу; шрифт мельче на 23–50 %, но на крупных ударах цифра растёт.
- Против каши ([Bugnet](https://bugnet.io/blog/how-to-fix-floating-damage-numbers-overlapping-into-an-unreadable-blob)): случайный разброс по x, чередование дуг влево/вправо, накопление быстрых ударов в одну цифру, пул и предел числа цифр на экране.
- WoW SCT/PlateSCT и аддоны ([Blizzard forum](https://us.forums.blizzard.com/en/wow/t/scrolling-combat-text-options/2096456)): порог минимального урона, фильтр «только мои», крит с коротким «pow» (въезд, сжатие, отскок), цвет по смыслу (DoT оранжевый, обычный белый, крит золотой, лечение зелёный); числа на нейм-плейте обрезаются — лучше вылет в сторону ([Last Epoch forum](https://forum.lastepoch.com/t/floating-combat-text-placement-emphasis-duration-speed-length-custom-elements/22864)).
- Lost Ark / Albion / MapleStory / RO / D4 / PoE (по памяти, источниками не проверено): крит — крупнее и со вспышкой/обводкой, но не гигантский; в толпе чужие цифры бледнее; мелкие тики сливаются.
- Что сделано (effects.ts `number`): старт на уровне полоски и вылет в сторону ±12–22 px — середина цели (полоска, ник) свободна; входящие по герою — вправо-вниз, красным; тики DoT суммируются раз в 0,9 с; крит — 9 px с «попом» масштаба 1,6→1,15 (Back.easeOut); толпа — чужие мельче и прозрачнее (уже было); предел 40 цифр (24 для мелких/чужих, 60 для крит); обводка: V1 тёмная 3 px, V2 крит с тёплой обводкой, V3 крит с обводкой 4 px.
