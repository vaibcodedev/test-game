# Управление: аудит и спецификация (задача 115)

Цель — управление уровня MMORPG: выбор цели отделён от атаки и движения, умения кастуются без лишних кликов, панели раскладываются свободно, клавиши переназначаются. Сервер по-прежнему авторитарен, клиент шлёт намерения.

**Решения пользователя (2026-10-19), имеют приоритет над текстом ниже:**
- ЛКМ по врагу — **только выбор** (как WoW). Опция «ЛКМ атакует» по умолчанию **выкл**. Атака — ПКМ по врагу, T, атакующее умение.
- Схема по умолчанию у новых игроков — **«Экшен»** (раздел 11); «Классика» — в настройках. Старым игрокам при первом входе показать выбор схемы (по умолчанию «Экшен»).
- Режим прицела по умолчанию — **«С превью»**: пока клавиша зажата — кольцо дальности и область/линия, каст при отпускании. «Быстрый» и «С подтверждением» — в настройках.

## 1. Как сейчас
- Клавиатура: один `keydown` на window (client/src/game/GameScene.ts:330), клавиши зашиты в `if/else` по `e.code` (раскладка не важна — оставить). WASD/стрелки — движение с предсказанием; 1–9 — умения; Q/E — зелья HP/MP; Tab — следующий враг (420 px, на арене 1400); Space — ближайший мешок (≤112 px), иначе NPC; F — NPC рядом (≤110 px); X/Shift+X — маунт; G/Shift+G — питомец; I C K M B P, F10 — окна; Enter — чат; Esc — окно → цель → меню. `HOTKEYS` (client/src/ui/gamemenu.ts:4) — только текст справки.
- Мышь (`pointerdown`, ЛКМ = ПКМ): мешок (16 px) → узел ресурса (24 px) → NPC/камень телепорта (18 px) → ПКМ по игроку — меню обмена → враг (лекарю и союзник) → иначе `moveTo` и снятие цели. Удержания нет, клик-движение не предсказывается (GameScene.ts:619).
- Цель = атака: `target` на сервере сразу включает подход и автоатаку (server/src/game/World.ts:767–777), `moveTo` цель сбрасывает (server/src/rooms/common.ts:52).
- Умения: слот = индекс в `activeSkills(cls)`, отсортированном по полю `slot` (data/skills*.json, shared/skills.ts:333). Сервер кастует по id (`skill {id,x,y,target}`), о слотах не знает. Панель пересобирается целиком на каждое `self` (client/src/ui/hud.ts:616). `point` летит в цель, если она есть, иначе в курсор; `aimAtCursor` (hud.ts:81) нигде не включается. GCD и очереди нет.

### Проблемы и баги
1. Tab и клик по врагу сразу ведут героя к нему: Tab в лагере — случайный пулл; выбрать, не атакуя, нельзя.
2. Клик по земле снимает цель — кайтить кликами нельзя, после шага цель выбирать заново.
3. После WASD герой сам бежит обратно к цели (World.ts:767) — нельзя отойти, лучник «прилипает».
4. `enemy`-умение без цели — только тост; нет каста по наведению, на себя, автоцели; вне дальности — «Цель слишком далеко» без подхода; дальность нигде не видна.
5. Нажатие на перезарядке молча теряется (server/src/game/skills.ts:49), удержание клавиши игнорируется (`e.repeat`, GameScene.ts:343); без GCD 9 умений вылетают за кадр.
6. Слоты с дырами: маг на 11 ур. имеет умения на 1, 2 и 5; запертые умения занимают клавиши; еду и прочие предметы на панель не положить; Q/E — жёстко два зелья, общий откат зелий 1,5 с не виден; `use` по индексу сумки — гонка при перекладке.
7. Каналы (`castUntil`: гимн, воскрешение, танец клинков) и `frozenUntil` арены клиенту не известны — WASD предсказывает шаг, сервер стоит → откат позиции.
8. `isTyping` (hud.ts:278) считает фокус на ползунке/флажке настроек вводом — после регулировки громкости WASD и хоткеи мертвы до клика по карте. Ctrl+C открывает окно героя. Кнопка HUD в фокусе + Space/Enter = повторное нажатие. В окнах свои разрозненные `stopPropagation`.
9. Справка и приветствие: «Умения: 1–4» (gamemenu.ts:4, hud.ts:260), нет G; F и Space почти дублируют друг друга, узлы ресурсов — только мышью.
10. Радиус попадания по юниту 14 px мира (client/src/game/UnitView.ts:369): на тачпаде промах уводит героя и снимает цель.
11. Кнопка умения на панели берёт точку прицела из последнего положения курсора над картой (Phaser не видит курсор над HUD).

## 2. Что берём
- WoW: выбор ≠ атака (ЛКМ — выбрать, ПКМ — атаковать); Tab/Shift+Tab; F1–F5 — группа; каст по наведению и Alt — на себя; очередь 400 мс; GCD; автобег; замок панелей и Shift-перетаскивание; красный хоткей «вне дальности», синий — «нет маны»; строка ошибок по центру.
- Albion, Ragnarok: клик-движение и атака кликом с подходом на дистанцию; в Ragnarok — «нажал умение → клик по цели».
- Diablo, Lost Ark, PoE: удержание кнопки — движение за курсором, умения в курсор, быстрый каст с индикатором.
- LoL, Albion: режимы прицела «быстрый / с превью по отпусканию / с подтверждением».
- Tibia: «преследовать цель / стоять», хоткеи выключены, пока открыт чат.

## 3. Схема по умолчанию («Классика»)
| Действие | Ввод |
|---|---|
| Идти | WASD, стрелки (8 направлений); ЛКМ по земле; удержание ЛКМ/ПКМ на земле — за курсором |
| Автобег, следовать | R или NumLock; Shift+F — за целью |
| Выбрать цель | ЛКМ по юниту; Tab / Shift+Tab — следующий/предыдущий враг; F1 — себя, F2–F5 — группа; Esc — снять |
| Атаковать | ПКМ по врагу, T; ЛКМ по врагу — только при включённой опции «ЛКМ атакует» (по умолчанию выкл) |
| Панель 1 / 2 | 1–9, 0, Q, E / Shift + те же (Q, E по умолчанию — зелья HP, MP) |
| Взаимодействовать | F или Space; ЛКМ/ПКМ по объекту |
| На себя | Alt + клавиша союзного умения |
| Маунт, питомец | X, Shift+X; G, Shift+G |
| Окна, чат | C, I, K, M, B, P, L (задания), F10; Enter или `/` — чат |
| Отмена | Esc: прицел → очередь/подход/канал → окно → цель → меню |

## 4. Цель
- Выбор не атакует и не двигает. Атаку включают ПКМ, T, ЛКМ по врагу (только если опция «ЛКМ атакует» включена; по умолчанию выкл), любое атакующее умение по цели.
- Клик по земле и WASD цель не снимают — выключается только преследование. Цель снимают Esc, смерть, невидимость, расстояние > 900 px.
- Tab: враги в 420 px (арена 1400) с прямой видимостью; сначала те, у кого `target` — я, затем по расстоянию; список замораживается на 2 с, повторный Tab идёт по кругу без повторов; Shift+Tab — назад.
- Союзник: ЛКМ по своему игроку/питомцу выбирает его любому классу; F1–F5 и клик по рамке группы. Сервер принимает союзника как выбор без атаки.
- Кольцо выбора: враг красный, союзник зелёный; рамка цели показывает расстояние и «вне дальности».

## 5. Перемещение
- WASD: 8 направлений, нормированный вектор, предсказание (как сейчас). Любое нажатие отменяет клик-путь, автобег, следование, подход к цели, отложенные подбор и разговор.
- Клик по земле: путь A* до точки (сервер `moveTo`, остановка в точке — tests/move.ts), маркер. Клиент строит тот же путь (shared/path.ts) и предсказывает шаг — без задержки RTT.
- Удержание кнопки на земле > 200 мс: клиент шлёт `input {mx,my}` дробным вектором к курсору (сервер уже нормирует, common.ts:41), мёртвая зона 12 px; отпустил — стоп. Предсказание то же, что у WASD.
- Автобег: по последнему направлению (стоял — к курсору); A/D поворачивают на 45°, S, клик или повтор R — стоп.
- Следование (Shift+F, пункт «Следовать» в меню ПКМ по игроку): сервер `follow {id}` держит 40–60 px по пути; рвётся движением, кликом, дистанцией > 600 px; тосты «Вы следуете за …» / «Следование прервано».
- Атака: после команды «атаковать» герой подходит до `attackRange + радиус цели − 4` и бьёт (как сейчас). После WASD/клика стоит (режим «Стоять»); если цель в дальности и герой стоит — автоатака продолжается сама. Опция «Преследовать цель» возвращает старый подход.
- Каст вне дальности (опция «Подходить к цели», вкл): сервер запоминает каст на 4 с, ведёт героя до дальности и видимости, кастует; WASD, клик, Esc, другое умение отменяют.
- Во время каста: мгновенные умения — на ходу. Каналы и касты (гимн, воскрешение, танец, телепорт 3 с, маунт 2 с) прерываются движением; сервер шлёт `cast {ms,name}`, клиент рисует полосу и не предсказывает шаги, пока сервер держит героя (`castUntil`, `frozenUntil`, оглушение, корни).
- Маунт: X — призыв 2 с стоя, движение отменяет; предсказание со скоростью маунта; атака и умения спешивают (как сейчас).

## 6. Касты
- Адресат: (1) юнит под курсором подходящего типа (опция «Каст по наведению», вкл), цель при этом не меняется; (2) выбранная цель; (3) `ally` — на себя (Alt — всегда на себя); (4) `enemy` — при опции «Автоцель» ближайший враг в дальности, иначе ошибка «Нет цели».
- Новые поля умения (data/skills*.json, SkillDef в shared/skills.ts): `aim` — `unit|ground|dir|dash|self` (выводится из `target`, для `point` задать вручную), `area` — радиус превью (по умолчанию `v(r).radius`, у рывков `v(r).dist`), `offGcd`.
  - ground (метеор, град стрел, круг, огненная стена, ловушка, лужа крови, знамя…) — точка курсора, зажата дальностью (сервер зажимает так же, skills.ts:222);
  - dir (огненный шар, залп, веер, пронзающий выстрел, бросок) — направление на курсор; курсор над HUD — на цель, иначе вперёд;
  - dash (мерцание, перекат) — в курсор.
- Режимы прицела (настройка): «С превью» (по умолчанию) — пока клавиша зажата, видны кольцо дальности и круг/линия, каст при отпускании; «Быстрый» — каст сразу при нажатии; «С подтверждением» — нажал → прицел → ЛКМ, ПКМ/Esc — отмена. Умения `unit`/`self` в режиме «С превью» кастуются при отпускании без задержки (превью — только кольцо дальности).
- Превью: кольцо дальности вокруг героя (красное, если точка/цель дальше), круг `area` у курсора, линия для dir; наведение на слот тоже показывает кольцо.
- GCD 0,75 с (data/balance.json `gcd`), `offGcd` у рывков и защит (мерцание, перекат, щитовой блок, скрытность…), тонкая полоса GCD на слотах.
- Очередь: нажатие за ≤ 400 мс (настройка 0–500) до конца перезарядки/GCD/каста сервер запоминает (одно умение, новое заменяет) и выполняет в первый готовый тик; слот в очереди — золотая рамка. Удержание клавиши = повтор каждые 150 мс.
- Esc снимает прицел, очередь, подход, канал (`cancel`), дальше — прежняя цепочка.

## 7. Взаимодействие (F / Space)
- Приоритет: объект под курсором (запас 24 px) → ближайший в 110 px: мешок → узел ресурса → NPC → камень телепорта → встреча; в 110–300 px — подойти и выполнить по прибытии. Порталов-объектов в игре нет, их роль у камней телепорта.
- Над ближайшим объектом подсказка «[F] Поговорить: Торговка Марфа», «[F] Подобрать», «[F] Добыть: Кристалл».
- ЛКМ и ПКМ по мешку/узлу/NPC — то же действие. Мешок подбирается целиком (как сейчас).

## 8. Панели и слоты
- Модель (новый shared/hotbar.ts): 2 панели × 12 слотов; слот — `null | {s: idУмения} | {i: baseПредмета} | {a: "mount"|"pet"|"attack"|"interact"}`. Клавиши панели 1: 1–9, 0, Q, E; панели 2 — с Shift (ряд над первой, скрыт, пока пуст). Хранится на сервере в `PlayerSave.bars`, приходит в `SelfState.bars`; в арене та же раскладка.
- Поле `slot` в данных умений становится «местом по умолчанию» (миграция, автостановка); `activeSkills`, деревья и sim его порядок сохраняют.
- Раскладка слотов и клавиши (сервер хранит только слоты, схема решает клавишу; `BAR_ACTIONS` в keybinds.ts). Слоты 0–8 — умения, 9–11 — предметы. «Классика»: 1–9, Q, E, 0 (слот 11 = `slot10`, Digit0). «Экшен»: Q W E R A S D F T, 1, 2, 3. Панель 2 — те же клавиши с Shift. Предметов в «Экшене» три клавиши (1–3), а не четыре: в ряду 12 слотов, 9 заняты умениями; Digit4 свободна для переназначения. В «Экшене» автобег ушёл с Shift+R на V (Shift+R — слот 4 панели 2).
- Миграция: нет `bars` → изученные активные умения на места, где их вызывали клавиши (порядок среди активных = слот 0..8), hp_potion на слот 9 (Q / 1), mp_potion на слот 10 (E / 2). Новый герой — так же (стартовое умение + зелья). Неизученные не ставятся: при изучении они встают сами.
- Автостановка: умение изучено (ранг 0→1) → сервер ставит его в слот `slot`, если свободен, иначе в первый свободный панели 1, затем 2; тост «Огненная стена — клавиша R» (сервер шлёт `slot {bar,i}`, подпись клавиши дописывает клиент по своей схеме).
- Перетаскивание (HTML5 DnD, как сумка и банк, hud.ts:810): из дерева K (изученные активные) и из сумки I (зелья, еда, будущие свитки телепорта; экипировку нельзя) на слот; между слотами — обмен; за панель — снять (предмет остаётся в сумке).
- Замок (вкл по умолчанию, кнопка у панели): закрытая панель принимает новое, но не двигает и не снимает; Shift+перетаскивание работает всегда.
- Предметный слот ссылается на `base`: сумма стопок, серый при 0, `use:base {base}` (сервер берёт первую стопку, нет гонки индексов). Общий откат зелий виден на всех зельях (`cd {id:"potion"}`).
- Слот показывает: хоткей из раскладки (`⇧1`), перезарядку (заливка + секунды), GCD, нет маны (синий), вне дальности или нет видимости (красный хоткей), нет цели (тусклый), не изучено (замок), очередь (золото), канал (свечение), количество. Панель строится при смене раскладки/класса, кадр меняет только классы и тексты (полная пересборка ломает DnD и подсказки).
- Сервер: `bars:set {bar,i,ref}`, `bars:swap {a,b}`; проверка индексов, умение своего класса (можно неизученное), предмет расходуемый, действие из белого списка, не чаще 10/с. Каст по id не меняется — номер слота серверу не нужен.

## 9. Клавиши: переназначение и защита ввода
- client/src/game/keybinds.ts: действие → до 2 сочетаний `{code, shift, ctrl, alt}` или кнопка мыши (СКМ, Mouse4/5); пресеты «Классика» и «Экшен»; `localStorage keybinds:v1`; по желанию копия в аккаунте (`prefs`, JSON ≤ 4 КБ).
- «Настройки → Управление»: группы (Движение, Цель, Панель 1, Панель 2, Интерфейс); клик → «Нажмите клавишу» (Esc — отмена, Backspace — очистить); конфликт — поменять местами; «Сбросить»; запрещены Ctrl+W/T/N/Tab, F11, F12, Alt+F4. Опции из разделов 4–8 и «Крупные цели».
- Один диспетчер `keydown`: хоткеи молчат только при фокусе в текстовом поле (`input` text/search/number/password, `textarea`, `select`, `contenteditable`); ползунки, флажки, кнопки не мешают; кнопки HUD теряют фокус после клика; Ctrl+буква — не хоткей, если не назначено; F1–F5 и Tab — `preventDefault`. Справка и подписи строятся из раскладки.
- Чат: Enter или `/` — фокус, Esc — выйти без отправки; пока открыт, герой стоит, хоткеи молчат.

## 10. Обратная связь
- Строка ошибок над панелью вместо тостов: 1,5 с, одинаковая — не чаще 2 раз в секунду, тихий звук «тук». Тексты с тем, чего не хватает: «Нет цели — Tab или клик по врагу», «Слишком далеко: ещё 3 кл.», «Нет прямой видимости», «Не хватает маны: 12 из 20», «Перезарядка: 2,4 с», «Не изучено — откройте K», «Нет зелий здоровья — у торговки».
- Клиент проверяет цель, дальность, ману, перезарядку до отправки (отклик без RTT); сервер — судья, `toast` получает поле `code` (`target|range|los|mana|cd|learn`) для звука и красной вспышки слота.
- Нажатие — вспышка слота; маркер клика; кольцо цели; подсказка взаимодействия; полоса каста; звук постановки в очередь.

## 11. Режим «Экшен» (Diablo, Lost Ark) — пресет по умолчанию
- ПКМ по земле (клик — путь до точки, удержание — движение за курсором); ПКМ по врагу — атака (подход + автоатака); ПКМ по NPC/мешку/узлу — взаимодействие. WASD выключены.
- ЛКМ по врагу/союзнику — только выбор цели (решение пользователя); ЛКМ по земле цель не снимает и героя не двигает; ЛКМ по NPC/мешку/узлу — взаимодействие.
- Умения панели 1: Q W E R A S D F T; предметы — 1–4; G — взаимодействие; Tab — цель; X, Z — маунт, питомец.
- Все умения в курсор: ground/dir/dash — в точку, unit — враг под курсором, иначе ближайший к курсору в 80 px, иначе цель.

## 12. Тачпад и ноутбук
- Играется без удержания: клик-движение, автобег на R, двухпальцевый тап = ПКМ (атака, взаимодействие).
- «Крупные цели»: радиус попадания 14 → 24 px и магнит — клик в 32 px от врага выбирает его, а не уводит героя.
- Без NumLock и F-клавиш: автобег — R, группа — клик по рамкам; всё переназначаемо. Колесо/жест — масштаб камеры 2–3 (опция).

## 13. Протокол
- Меняются: `target {id}` — только выбор (враг или союзник); `skill` — очередь, подход, GCD; `toast` + `code`; `cd` с `id:"potion"` и `"gcd"`.
- Новые от клиента: `attack {id|null}`, `follow {id|null}`, `cancel`, `use:base {base}`, `bars:set`, `bars:swap`. От сервера: `cast {ms,name}`. Поля `SelfState.bars`, `PlayerSave.bars`.
