# Визуальный стиль «Пепельного Предела»

Единый справочник по внешнему виду игры: интерфейс (DOM и CSS), игровой мир (Phaser), canvas (миникарта, карта мира), пиксель-арт (процедурная генерация), лаунчер десктопа. Раздел 1 — обязательная система (задача 126, сделана): всё новое и всё правимое строится по ней. Аудит до задачи 126 (commit 9855f20) — в истории git.

Как пользоваться:
- Раздел 1 — правила. Новый экран, компонент, предмет или эффект делается по ним.
- Раздел 2 — осознанные исключения, их не «чинить».
- Раздел 3 — что ещё не сделано по задаче 126. Исправленное здесь не перечисляется: см. PLAN.md и git log.
- Раздел 4 — рекомендации по унификации (предложения).
- Раздел 5 — чек-листы для новых экранов, компонентов, предметов и эффектов.
- Раздел 6 — что не удалось установить по коду.

Смежные документы: `docs/gear-visuals.md` (заточка, редкость, вид вещей на герое), `docs/controls.md` (управление), `docs/raid.md` (рейд). При расхождении с ними верен код.

## 1. Обязательная система

Правило одно: сначала токен или компонент из библиотеки. Нового смысла — новый токен в `:root`, а не сырой hex, не inline-стиль и не свой класс-дубль.

### 1.1 Токены

Источник: `client/src/styles/tokens.css` (`:root`). Цвета для TS, canvas и Phaser — `shared/palette.ts` (`P`); совпадение с `:root` проверяет `tests/style-tokens.ts`.

- **Цвета:** фон `--bg`; поверхности `--panel`, `--well` («колодец»: ячейки, поля, полосы), `--card`, `--btn`, `--btn-hover`, `--btn-primary`, `--btn-danger`, `--sel` (выбрано), `--overlay` (подложка окна); линии `--line`, `--line-hi`; текст `--fg`, `--dim`; акцент `--gold`; ресурсы `--hp`, `--mp`, `--xp`; состояния `--ok`, `--bad`, `--bad-line`, `--warn`; редкость `--common`, `--rare`, `--epic`, `--legend`; заточка `--enchant` (только для заточки); мир `--foe`, `--ally`, `--self`, `--heal`, `--num-gold`, `--boss`, `--boss-soft`, `--team-1`, `--team-2`.
- **Лого игры** (экран загрузки): эмблема `client/public/ui/logo-emblem.png` (105×118) над названием — целым множителем пикселя экрана (×2, на высоких окнах ×3, на низких ×1, `image-rendering: pixelated`, `styles/loading.css`); название — `--fs-head-logo` (кегль по правилу заголовков; при масштабе экрана он округляется вверх до 64px, поэтому блок `.ld-box` шире названия: 580px, и название стоит в одну строку; в узком окне переносится, полосы золота повторяются на каждой строке), золото бренда `--logo-hi`, `--logo`, `--logo-shade` — одно для обеих фракций.
- **Кегли:** `--fs-2xs` 10, `--fs-xs` 12, `--fs-sm` 13, `--fs` 14 (база), `--fs-md` 16, `--fs-lg` 18, `--fs-h` 20. Кеглей вне шкалы не вводить.
- **Отступы:** `--sp-0` 2, `--sp-1` 4, `--sp-1h` 6, `--sp-2` 8, `--sp-3` 12, `--sp-4` 16, `--sp-5` 24. Поля окна — `--pad-win`.
- **Радиусы:** `--r-1` 3 (полосы), `--r-2` 4 (кнопки, ячейки, поля, тосты), `--r-3` 6 (панели, окна), `--r-pill` 12 (чипы, ползунки).
- **Высоты:** `--ctl-h` 32 (контрол), `--ctl-h-sm` 28 (малый контрол).
- **Ширины окон:** `--win-s` 360, `--win-m` 460, `--win-l` 640, `--win-xl` 760; `--set-ctl-w` 200 — колонка контролов в настройках.
- **Курсоры:** `--cur-arrow`, `--cur-pointer`, `--cur-grab`.
- **Рамка:** `--frame-w` 12, `--frame-slice` 12, `--div-h` 22, `--div-cap` 16 (рамка окна и разделитель заголовка).
- **Тени:** `--shadow-panel` (панель), `--shadow-head` (тень заголовка), `--shadow-text` (тень текста мира), `--outline-text` (контур надписи поверх картинки), `--glow-boss`; шторка перезарядки — `--shade-cd`.

Цвет фракции задаёт `body[data-faction]`: Сольгард — акцент `#d6a84b`, Умбрат — `#8fd46a`. Линии, панели и акценты берутся из токенов, поэтому тема переключается без правок компонентов.

### 1.2 Шрифты

- **Текст — Rubik** (`--font`), начертания 400 и 600 (`--fw`, `--fw-b`). Больше начертаний не использовать.
- **Заголовки — Ark Pixel 10** (`--font-head`, `client/src/styles/fonts.css`), одно начертание. Кегль пиксельного заголовка — только `round(nearest, желаемый, var(--hu))`, где желаемый — токен `--fs-head-*` (19, 27, 32, 38 px), а `--hu` = 10px / (devicePixelRatio × масштаб интерфейса). `--hu` ставят `main.ts` и `hud.ts`, у лаунчера — медиазапросы. Так буквы ложатся на пиксели экрана.
- Своих кеглей пиксельному шрифту не задавать. Пробел — `--head-ws`, тень заголовка — `--shadow-head`.
- Мелкие заголовки (`.sec-h`, `.sub-h`, заголовки магазинов) — Rubik.
- Числа — `font-variant-numeric: tabular-nums`.
- **Мир (Phaser):** Rubik, только через `worldText` (раздел 1.7).

### 1.3 Каркас окна

- Структура: `.win` (или `.dialog` для модального) → `h2` (шапка: за неё тянут, в конце кнопка `.x`) → `.body` (единственная прокрутка) → `.win-foot` (подвал: главные кнопки, `.gold-amt` у правого края).
- Ширина: `.win.s` / `.m` / `.l` / `.xl` (360 / 460 / 640 / 760 px), не шире `calc(100vw − 24px)`. Высота не больше `calc(100vh − 140px)`.
- Заголовок окна — только `h2`. **`h2` в теле окна не использовать.** Разделы тела — `.sec` с заголовком `.sec-h`; группы внутри раздела — `.sub-h`.
- Рамка окна и диалога — Kenney Fantasy UI Borders, вариант B (`border-image`, `client/public/ui`). Фон — `--panel`.
- Модальное окно — только через `openModal()` (`client/src/ui/kit.ts`): подложка `.modal` на `--overlay`, диалог `.dialog`; Esc и клик по подложке закрывают.
- Слои: окна NPC — z-index 4, модальные — 5, меню Esc — 9000, экран загрузки — 15000 (`ui/loading.ts`), системные — 20000, тултип — 100000.
- Окно «Авторы» (меню Esc → «Авторы», `ui/credits.ts`, текст — `data/credits.json`, стили — `styles/credits.css`): `.win.l` → `.body` с разделами `.sec`; строки — `.list.boxed` / `.row`, лицензия — плашка `.chip.dim` (у CC — ссылка на текст лицензии), список иконок по авторам — `.disclosure`. Ссылки золотые, в новой вкладке (`target="_blank" rel="noopener noreferrer"`). Esc закрывает окно общим `Hud.closeTop`.

### 1.5 Правила текста

- Подписи с заглавной буквы, без точки в конце. Кнопки — глаголом («Купить», «Продать все»).
- Без обрезки многоточием: длинный текст переносится, окно расширяется. Многоточие допустимо только в шапке окна (`h2 > span`) и в подписи кнопки (`.btn > .lbl`).
- Числа — tabular-nums, разряды через пробел. Золото — только `.gold-amt`. Секунды — `toFixed(1)` и « с».
- Выбор — `aria-pressed` (кнопки, чипы) или `aria-selected` (вкладки). Один смысл — один цвет: враг `--foe`, ошибка `--bad`, успех `--ok`, предупреждение `--warn`, золотые цифры `--num-gold`.

### 1.6 Состояния и движение

- Наведение: рамка `--gold`, мгновенно. Фокус с клавиатуры: `outline 2px --gold`. Нажатие: сдвиг `translateY(1px)`. Выключено: непрозрачность .45, курсор-стрелка. Выбрано: `--sel` и рамка `--gold`.
- Ячейка, которую нельзя надеть, — серая. Пустой слот — .45. Перетаскивание — пунктир и золотая цель.
- Анимация отклика — короче 0,3 с; баннеры — до 3 с. Длинную или повторяющуюся анимацию отключать при `prefers-reduced-motion`.

### 1.6a Слои (z-index)

Числа живут только в `tokens.css` (`--z-*`); везде иначе — `z-index: var(--z-…)` (проверяет tests/ui-layers.ts). Внутри компонента — `--z-l0…--z-l5`.

### 1.7 Мир (Phaser)

- Подписи (ник, титул, цифры урона, реплики, таблички) создаются только через `client/src/game/worldText.ts`: пресеты кегля и обводки, разрешение текста равно зуму камеры, позиции — целые пиксели. Новый текст мира — через него.
- Цвета мира — из `shared/palette.ts` (`P`), синхронно с `tokens.css`. Вшитых hex в TS и canvas не оставлять.
- Пиксель-арт: масштаб камеры и спрайтов целый; дробный масштаб не применять.
- Курсоры мира: `client/src/game/cursor.ts` — меч на враге, рука на NPC, перчатка на добыче.
- Заточка и редкость на герое — по `docs/gear-visuals.md` и `data/gear-fx.json`.

### 1.8 Ассеты и иконки

- **Рамка окон** — Kenney (CC0), **курсоры** — Kenney Cursor Pixel Pack (CC0, золотые), **ячейки, полосы HP/MP, рамка портрета, хотбар** — LiteUI Fantasy (перекрашен в нашу палитру). Картинки лежат в `client/public/ui`, исходники паков — в `vendor/` (локально, git их не хранит). Без картинок интерфейс остаётся в CSS-виде.
- **Иконки умений:** стиль frosty_rabbid, 24×24 в пикселях ×2, цвет по стихии умения, знак — по смыслу (молния, капля, череп и т. п.). Плашка и рамка тёмные, нейтральные, без синего налёта.
- Все иконки: `image-rendering: pixelated`, целый масштаб.
- Заточка на значке — только `+N` в ячейке, бирюзой `--enchant` (от +4). Обводки и заливки на ячейке нет.
- Пиксель-арт: генератор `tools/gen/*` с палитрой `P` (`tools/gen/palette.ts`), контур 1 px цветом `OUTLINE`, свет сверху слева. Подробности — раздел 5.5.

### 1.9 Запреты

- Новые цвета вне `tokens.css` и `shared/palette.ts`.
- Inline-стили (`style="…"`, `el.style.color = …`). Исключение — динамика: ширина полосы (`--p` или `style.width`) и цвет по данным через `--c`.
- Свои кегли пиксельному шрифту (кегль вне `round(nearest, …, var(--hu))`).
- Дробный масштаб пиксель-арта и подписей мира.
- Свой чекбокс, свой ползунок, своя рамка редкости, свой градиент кнопки.
- `h2` в теле окна; многоточие в подписях (кроме 1.5).

## 2. Исключения (осознанные)

- Заточка +1…+3 не бирюзовая ни в значке, ни в тултипе (`docs/gear-visuals.md`, 2.2).
- Обводки и заливки заточки на ячейке нет, только значок +N (решение пользователя).
- В чате имя героя Сольгарда красится цветом класса, Умбрата — цветом фракции: цвета классов совпадали с эпиком и бирюзой.
- Элита перекрашивает ник в `#ffd24a` поверх цвета врага или команды (`UnitView.ts:318`).
- Рейд-босс рисуется отдельно (`raidBoss.ts`): своя тень, кольцо и подпись, без полоски HP над головой; цифры урона крупнее в 1.2 раза (у крита в 1.4). Цвета и шрифт — по разделу 1.
- Героев при наведении не подсвечивает: тинт только у мобов.
- Сцена выбора героя использует свой градиент выбора `#4a3824 → #2a1e18` (`.cs-slot`).
- Контур в арте: у деревьев, цветов и кустов — `#1b1422` с α 140; у воды и подводных объектов — `#102030` α 160; у рейд-босса — `#08040a`; у маунтов — по 8 соседям.
- Легендарные иконки могут иметь ореол темы, искры и светящиеся глаза; иконкам каталога это запрещено.
- Наземные и летающие маунты проецируются по-разному (`mounts.ts:36-37`).
- Вода, лава и земля — отдельные анимированные текстуры 64×64 вне схемы масок; их не менять.

Не исключения, а часть общего стиля (решение пользователя): **плашка цели, рейд-HUD и миникарта** — токены, кегли `--fs-*`, палитра `--boss` и `shared/palette.ts`, компоненты раздела 1.4. Компактность достигается отступами и размером токенов, а не своими кеглями и цветами.

## 5. Правила для нового

### 5.1 Новый экран или окно
- Корень — `.panel` + `.win` + `.win-<имя>`; шапка `h2` (Ark Pixel по формуле `round(nearest, …, var(--hu))`, `--gold`, разделитель из рамки) с кнопкой `.x`. Ширина `min(Npx, calc(100vw − 24px))`, высота не больше `calc(100vh − 140px)`, содержимое прокручивается.
- z-index: обычное окно — 4, модальное — 5 с подложкой `--overlay`. Выше 9000 — только системные окна.
- Текст `--fs` 14px `--fg`, вторичный `--dim` `--fs-xs`; разделы `.sec-h` 16px `--gold`.
- Цвета только через токены `:root`, чтобы работала тема фракции. Новый смысл — новый токен в `:root`, а не сырой hex.
- Отступы и радиусы только токенами (раздел 1.1): зазоры `--sp-1`–`--sp-2`, поля `--pad-win`, радиус `--r-2` для элементов и `--r-3` для панелей.
- Проверка на ширине 800px и меньше (`@media (max-width: 800px)`).

### 5.2 Новый компонент
- Кнопка — `.btn` с модификатором (`.primary`, `.small`, `.danger`); свой градиент не придумывать.
- Выбор — `aria-pressed` (кнопки, чипы) или `aria-selected` (вкладки); оформление — `--sel` и рамка `--gold`.
- Обязательны `:hover` (рамка `--gold`), `:focus-visible` (`outline 2px --gold`), `:disabled` (.45).
- Ячейка предмета — `.cell r{редкость}` + значок `plusBadgeN` (`client/src/ui/smith.ts`); иконку брать из `iconFor()`; свою рамку редкости не рисовать.
- Ошибку действия — через `toast({code})` → строку ошибки; не открывать для этого отдельное окно.
- Динамика (ширина полосы, цвет) — через CSS-переменную (`--c`, `--p`) или `style.width`; остальное — классами.
- Анимация короче 0,3 с для откликов и до 3 с для баннеров; длинную или повторяющуюся анимацию отключать при `prefers-reduced-motion`.

### 5.3 Новый предмет
- Данные — в `data/items.json` (каталог), `data/legendaries.json` (легендарки); характеристики одинаковы для обеих фракций, `fac` влияет только на стиль вида.
- Редкость видна только каймой и камнем на иконке и рамкой ячейки; ореол на иконке не рисовать (`docs/gear-visuals.md`).
- Синий, фиолетовый, оранжевый и бирюзу в отделке использовать только по смыслу редкости и заточки (2.6). Ткани и металлы этих оттенков допустимы внутри силуэта.
- Эффект вещи на герое рисуется только в пределах самой вещи и укладывается в лимиты `data/gear-fx.json` (2 источника, 8 частиц).
- Иконка 48×48, вид на герое — через `GearLayers.ts` и `GearModelSprites.ts`; подробности генерации — в 1.8 и 5.5.

### 5.4 Новый игровой эффект
- Глубина — из `DEPTH` (`terrain.ts:13`): на земле `ground+N`, в воздухе `top−N`. Своих абсолютных чисел не вводить.
- Цвет школы — из `KIND_COLOR` (`effects.ts:17-26`); новый вид урона добавлять туда же.
- Частицы — через `burst()` (пул, `ADD`, не больше 36 за вспышку). Свои эмиттеры — с `maxAliveParticles`.
- Телеграф опасности — по образцу `effects.ts:354-396`: контур 2.5px с нарастанием α, заливка 0.16 → 0.36, цвет по стихии, красный по умолчанию.
- Тряска камеры — только через `shake()` с учётом расстояния; сила до 0.006 для обычных ударов, до 0.012 — для рейда.
- Бафы — круг под ногами (эллипс 0.45, обводка 1px) или тинт тела; общих аур вокруг героя без источника не делать (`docs/gear-visuals.md`).
- Новый цвет эффекта на герое отстоит от бирюзы `#3ff0d0` по тону не меньше чем на 40°.

### 5.5 Новый спрайт, моб, маунт или объект
- Рисовать генератором в `tools/gen/`, цвета брать из рамп `P` (`tools/gen/palette.ts`), новую рампу добавлять туда же (3–5 тонов, от тёмного к светлому).
- Свет сверху слева, внешний контур 1px `OUTLINE`, фактура — шумом `pnoise` и `hash01`, без антиалиасинга и плавных градиентов.
- Юнит: кадр 32 (босс 64, рейдовый масштаб 128), лист 12×3 (ходьба, атака, смерть × вниз, вверх, вбок), земля на y = 30 из 32.
- Маунт: на каркасе `Rig`, кадр 96–128, лист 12×6 с передним слоем, посадка `seat` для каждого кадра, иконка 48×48.
- Объект: размеры кратны 32, опора — низ середины; стиль города — общими `bricks`, `slabs`, `stallArt` и палитрой своего стиля.
- Фракционный вид — материалами и деталями (раздел 1.8 и `docs/gear-visuals.md`), а не свечением. Фракционные варианты делать для обеих фракций.
- После генерации — монтаж в `tools/out/` и сравнение с соседними ассетами того же типа.

### 5.6 Режимы
- Враждебность героя показывается красным ником и полоской (`FOE_COLOR`) и красным кольцом цели. На арене — цвета команд; в рейде врагов нет.
- Рейд-элементы интерфейса — блоки `.raid-*` с палитрой `--boss` (раздел 1.1) и не перекрывают полосу босса (плашка цели top 112px).
