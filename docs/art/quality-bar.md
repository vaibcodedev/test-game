# Планка арта и эффектов

**Когда читать:** перед любой работой с картинками — герои, мобы, боссы, NPC, маунты, объекты, здания, декор, предметы, иконки, эффекты, паки.
**Главное:** объём не хуже Warspear Online, стиль свой; всё через генератор `tools/gen` с палитрой `tools/gen/palette.ts`; масштаб только целый; хитбокс = силуэт кадра; перед показом — сравнение «наш | эталон», снимки днём и ночью на зуме 2 и 3; слабое не показывать.

Подробности по темам: перспектива и высота — [perspective.md](perspective.md), рост и масштаб — [scale.md](scale.md), иконки — [icons.md](icons.md), снаряжение и сеты — [gear.md](gear.md), анимация и VFX — [animation.md](animation.md), интерфейс — [ui-style.md](ui-style.md).

## 1. Главная планка владельца

- Объём и ощущение мира — **не хуже Warspear Online**. Всё, что не дотягивает, дорабатывается до показа.
- Стиль **свой**: палитра, тёмное фэнтези «Пепельного Предела», фракции. От Warspear берём только устройство 2D-мира — перспективу, высоты, объём, читаемость. Их формы, цвета и ассеты не копируем.
- Перед проектированием арта или эффекта смотреть, как это сделано в топовых MMO (WoW, Lineage 2, Lost Ark, Black Desert, Aion, Guild Wars 2, Albion; для 2D-мира — Warspear): сравнить 2–4 игры, взять лучшие практики, варианты владельцу — с пометкой, откуда идея.

## 2. Обязательно для всех ассетов

- Вид 3/4 (фасад и верх), свет сверху-слева, 3–5 тонов на материал, тени и блики.
- Контур 1 px тёмным тоном своего материала, не чистый чёрный. Без плоских заливок и без однопиксельного шума.
- Силуэт и пропорции — по референсу и по росту героя. Соседние вещи в одном масштабе, масштаб только целый (`setScale` для пиксель-арта не используем, перерисовываем в большем кадре). Силуэт читается на зуме 1,75–3.
- Анимации: 8–12+ кадров (герой и NPC — 12–16), плавно (easing, ≥ 12 к/с), живой покой. Все направления: вниз, вверх, вбок и зеркало. Ничего не вылезает за кадр. Подробно — [animation.md](animation.md).
- Тень: контактная у основания плюс динамическая. Ночью светящиеся части (огонь, глаза, руны) видны, у источников света есть ореол.
- Палитра — `tools/gen/palette.ts`, золото как в игре, акценты фракций по [ui-style.md](ui-style.md) (Сольгард `#d6a84b`, Умбрат `#8fd46a`). Иконки 48×48, не пустые, понятны с первого взгляда.
- Не мультяшно: реалистичные пропорции, сдержанная насыщенность, материал читается фактурой.

## 3. Хитбокс, наведение, опора

- Наведение и клик — по непрозрачным пикселям кадра на всю высоту, с небольшим допуском. Курсор, золотое или красное свечение и подсказка «G» совпадают с силуэтом. Общая маска — `client/src/game/objPick.ts`.
- Свечение при наведении — только контур 1–2 px экрана, без заливки.
- Непроходимость — по **основанию** на земле, а не по всей картинке. Точка опоры (ноги, основание) — позиция в мире, сортировка глубины по ней.
- Здание гаснет (становится полупрозрачным), когда герой за ним; крыша перекрывает героя за домом.
- Проверка — `tests/pick.ts`.

## 4. Генератор и паки

- Всё делается через генератор `tools/gen` (паки тоже через него: наша палитра и контур). Данные — в `/data`, не в коде.
- Исходники паков — `vendor/` (локально, git игнорирует), в игру — только через `tools/gen/vendor*.ts`; картинки UI — `client/public/ui`.
- `npm run assets` пересобирает всё и долго; без нужды не запускать. Атлас — отдельно: `tools/gen/atlas.ts`. Часть объектов ставится своими установщиками (`tools/volume-install-*.ts`, `to-game.ts`).
- Лицензии и авторы — [../content/credits.md](../content/credits.md) и `data/credits.json`. Паки с запретом раздачи — только в приватном репозитории; делать его публичным нельзя, пока они в истории (2026-10-21).

## 5. Перед показом владельцу

1. Сравнение «наш | референс или эталон пака» на одном зуме.
2. Снимок в игре днём и ночью на зуме 2 и 3, с героем рядом.
3. Проверка наведения и хитбокса (`tests/pick.ts`).
4. Слабое не показывать — доработать. Скриншоты после успешной проверки удалять; показанные владельцу — после его ответа.
5. Выбор и материалы (референсы) спрашивать через опросник заранее.

Референсы владельца (`refs/`, `tools/out/refs/`) — только образцы для сравнения: в игру и в git чужой арт не идёт.
