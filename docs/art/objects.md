# Каталог объектов мира

**Когда читать: любая правка объектов — бери список отсюда.** Машиночитаемый источник правды — [data/objects-catalog.json](../../data/objects-catalog.json); эта таблица собирается из него скриптом `npx tsx tools/objects-catalog.ts` (руками не править).

## Правило

- Новый объект в мире → после добавления запусти `npx tsx tools/objects-catalog.ts` и проверь, что объект появился в каталоге с названием и категорией (нет названия — допиши `tools/objects-names.ts`; тест `tests/unit/objects-catalog.ts` падает на объекте без записи).
- Правка объектов по просьбе владельца → список берётся из `data/objects-catalog.json` (поля: id, name, category, where, variants, generator, collision, animated, glow, quality).
- Источники: манифест `client/public/assets/manifest.json`; генерация карт `shared/map.ts`, `shared/dungeon.ts`, `shared/raid.ts`; интерьеры `data/interiors.json`; Цитадель v2 `data/citadel.json`; генераторы `tools/gen`.
