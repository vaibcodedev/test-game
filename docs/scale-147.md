# Задача 147: масштаб мира под героя Б (30 px)

## Переключатель

- **Флаг — `data/hero-b.json` → `enabled`** (сейчас `false`). Один на всё: включает героя Б (tools/gen/hero147, data/hero-base-b.json) и все листы, подогнанные под его рост. Включаются вместе.
- Без флага: **Колосс** (по слову владельца: «он же мировой» — сделан сразу и в текущей игре, свой лист `wb_colossus`).
- Устройство: `data/scale147.json` → `remap` (лист → лист `<id>_b147`); `client/src/game/scale147.ts` (`scaledSprite`, `skipUnitSheet`, `isScaledSheet`). BootScene не грузит листы `_b147` при выключенном флаге и раскладывает их как мобов задачи 140 (кадр 40 и 64); UnitView подменяет лист и считает кадр 40 обычным ростом (`big()`), у кадров ≥ 96 тень и кольцо ×кадр/80 (`shK`).
- Масштаб только целый: всё перерисовано генераторами в большем кадре, `setScale` не используется.

## Мерка

Рост — высота непрозрачного силуэта (alpha > 40) в покое, вид «вниз», медиана кадров; «до ступней» — без подошвы и контура (у героя Б и у рига — минус 2). Герой Б: 32 px до ступней (кадр 48, ступни y = 45), силуэт 34; прежний герой — 28 до ступней. Цели — по решениям владельца (раздел внизу).

| класс | цель до ступней, px | силуэт, px |
|---|---|---|
| гуманоиды, NPC | 32 ±2 (как герой Б) | 32–36 |
| малые расы (гоблины, кобольды, бесы) | ≈ 24 (¾ героя) | 24–28 |
| огры, тролли, големы | 1,4–1,7 героя | 47–56 |
| боссы зон / кольца | 1,5–2 / 2–2,5 героя; боссы-люди 1,2–1,4 | 50–66 / 66–82 |
| рейд-босс / Колосс | ≈ 3,5 / ≈ 4 героя | 106–118 / 120–136 |
| звери и маунты | на ~20 % крупнее жизненных пропорций | |
| двери и проходы | проём ≥ 34 | |
