# Задача 147: масштаб мира под героя Б (30 px)

## Переключатель

- **Флаг — `data/hero-b.json` → `enabled`** (сейчас `false`). Один на всё: включает героя Б (tools/gen/hero147, data/hero-base-b.json) и все листы, подогнанные под его рост. Включаются вместе.
- Без флага: **Колосс** (по слову владельца: «он же мировой» — сделан сразу и в текущей игре).
- Устройство: `data/scale147.json` → `remap` (лист → лист `<id>_b147`); `client/src/game/scale147.ts` (`scaledSprite`, `skipUnitSheet`, `isScaledSheet`). BootScene не грузит листы `_b147` при выключенном флаге и раскладывает их как мобов задачи 140 (кадр 40 и 64); UnitView подменяет лист и считает кадр 40 обычным ростом (`big()`), у кадров ≥ 96 тень и кольцо ×кадр/80 (`shK`).
- Масштаб только целый: всё перерисовано генераторами в большем кадре, `setScale` не используется.

## Мерка

Рост — высота непрозрачного силуэта (alpha > 40) в покое, вид «вниз», медиана кадров. Герой Б: 32 px от макушки до ступней (кадр 48, ступни y = 45), 34 с причёской и подошвой; прежний герой — 28–29 той же меркой. Отсюда множитель гуманоидов **k = 1,12**.

| класс | цель, px (герой 30) | правило |
|---|---|---|
| гуманоиды | 26–32 | ×1,12 к прежнему |
| малый народ (гоблины, кобольды, бесы, крысолюды, лягушатники) | 18–26 | ×1,12, ниже человека по лору — на решение владельца |
| NPC | как герой | строятся на основе Б + наряды gear147 |
| крупные звери, огры, тролли, големы | 40–56 | перерисовка в кадре 64 |
| боссы зон и колец | 48–72 | |
| рейд-босс | 80–96 | ниже Колосса |
| мировой босс Колосс | 96–128 | заметно больше всех |
| двери и проходы | проём ≥ 34 | под героя с запасом |
| деревья, дома, колонны | 2,5–5 героя; этаж ≈ 40 | реальная пропорция к человеку |

## Сделано

**Партия 0 — Колосс (в игре, без флага).** 73 → **127 px** (кадр 80 → 140, выше рейд-босса 119). Генератор `tools/gen/bosses139/sol_storm_colossus.ts`: разметка поз в прежних логических единицах, сетка Z = 3,5 (280×280) сводится 2:1; заклёпки, глаза, ядро молний — в пикселях кадра (не растягиваются). Лист перенесён по 56 столбцов (ширина ≤ 8192), края кадров чисты. Радиус 30 → 45 (`data/world-bosses.json`), тень и кольцо ×1,75, имя над макушкой (кадр ≥ 96). `tests/pick.ts`: макушка, плечо и «над головой — мимо» для кадра 140 (45 ok). Монтаж: `tools/out/scale147/colossus-before-after.png`. Сценарий `tests/ring-bosses-ingame.ts --boss=sol_storm_colossus` — все проверки ok (кадр 140, умения, фаза, гибель, консоль чиста), `tests/world-boss.ts` 59 ok.

**Внимание:** лист `sol_storm_colossus` общий у мирового босса Колосса и у босса кольца r75n «Гурдан Громобой» (ур. 75) — Гурдан тоже стал 127 px. Если босс кольца должен остаться в 48–72: развести листы (Колосс — свой id в каталоге боссов и `world-bosses.json` → mob.sprite, Гурдан — прежний кадр 80) — решение владельца.

**Партия 1 — мобы зон 1–40 (под флагом).** 62 листа `_b147` из рига `tools/gen/mobs` (`tools/gen/scale147/mobs-b.ts`, параметры — `data/scale147.json` → `mobs.rig`): гуманоиды ×1,12 в кадре 40 (кабанолюды 30, зомби 29–31, волколюды 30–32, сатиры 31–33, хобгоблины 30–34, мумии 30–31, упыри 26–27); малый народ ×1,12 (гоблины 22–24, кобольды 20–22, бесы 21–22, крысолюды 24–26, лягушатники 25–26); огры 36 → 47 (матёрые 53), тролли 28 → 46 (45) в кадре 64.
