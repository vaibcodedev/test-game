# Карта мира в Tiled: инструкция для владельца

**Сейчас это подготовка.** Игра по-прежнему строит мир кодом (`generateMap`), а файлы Tiled — копия для просмотра и проб.
Правки в Tiled **в игру пока не попадают**: это начнётся после «переключения» (план — `docs/libraries-2.md`, раздел 1).

## 1. Установить Tiled

1. Скачайте Tiled 1.12.1 с сайта https://www.mapeditor.org (кнопка Download, версия для Windows).
2. Установите и запустите.
3. Включите русский язык: «Edit → Preferences → General → Language → Русский». Перезапустите Tiled.

## 2. Сделать файлы мира

В папке игры выполните:

```
npx tsx tools/tiled/export.ts
```

Через 5–10 секунд в папке `tools/out/tiled/` появятся файлы: `main.world` (весь мир), 30 регионов `r0-0.tmj … r9-2.tmj`,
наборы `ground.tsx`, `cell.tsx`, `objects.tsx` и проект `ashen.tiled-project`.
Картинка всего мира без Tiled: `npx tsx tools/tiled/preview.ts` → `tools/out/tiled/preview.png`.

## 3. Открыть мир

1. «Файл → Открыть файл или проект» → `tools/out/tiled/ashen.tiled-project` (так появится список мобов).
2. «Файл → Открыть файл» → `tools/out/tiled/main.world`. Откроются все 30 регионов рядом (10 по ширине, 3 по высоте).
3. Колесо мыши — масштаб, пробел + мышь — сдвиг. Дважды щёлкните по региону, чтобы править его.

Слои (панель «Слои», справа). **Не переименовывайте их**: программа ищет слои по имени.

| Слой | Что это |
|---|---|
| Земля | поверхность: трава, песок, снег, вода, лава и т. д. |
| Проходимость | скрыт; красное — нельзя пройти, жёлтое — «резерв» (дороги, города, арены) |
| Зоны | границы зон (многоугольники); свойства: `zone` (номер), `name`, `level` |
| Постройки, Деревья и камни, Ресурсы, Декор | объекты мира с картинками |
| Мобы | точки мобов: `mob` (выбор из списка) и `level` |
| Боссы и арены | круг = арена босса |
| Точки, Телепорты, NPC, Патрули | точка появления, торговцы, камни телепорта, стражи и горожане, маршруты патрулей |

## 4. Красить землю (авто-переходы)

1. Выберите слой «Земля».
2. Откройте панель «Наборы Ванга» (Terrain Sets): «Вид → Панели → Наборы Ванга».
3. Выберите набор «Земля» и цвет: «Трава», «Песок», «Снег», «Грязь», «Вода» и другие.
4. Инструмент «Кисть наборов Ванга» (клавиша `T`) — рисуйте. Края между поверхностями Tiled подставит сам.
   Переходы есть для любой пары основных поверхностей. Если в точке сходятся три поверхности, а подходящей плитки нет, Tiled оставит место пустым. Тогда закрасьте его ещё раз одной из соседних поверхностей.

## 5. Объекты: ставить, двигать, удалять

- **Сдвинуть:** инструмент «Выделение объектов» (`S`), перетащить. Точка объекта — низ-середина картинки, как в игре.
- **Поставить:** выберите слой (например, «Деревья и камни»), в панели «Наборы тайлов» откройте «Объекты», выберите картинку,
  инструмент «Вставить тайл» (`T` в объектном слое) и щёлкните по карте.
- **Отразить:** выделить и нажать `X`.
- **Удалить:** `Delete`.
- **Копия (Ctrl+C / Ctrl+V)** копирует и свойство `id`. Это не страшно: проверка заметит повтор и посчитает копию новым объектом.
- Свойство `id` у старых объектов не меняйте. У новых объектов его можно не ставить.
- Указатели (`label` — надпись), ресурсы (`node`, `res`) — свойства в панели «Свойства».

## 6. Мобы, боссы, NPC, патрули

- **Моб:** скопируйте точку в слое «Мобы» и сдвиньте её. Вид моба меняется в свойстве `mob` (выпадающий список), уровень — в `level`.
- **Босс:** круг в «Боссы и арены». Центр круга — где стоит босс, размер — арена.
- **NPC:** точки в слое «NPC». В свойствах указано: `role` — роль (торговец, страж, место горожан…), `sprite` — вид, `place` — город или поселение.
- **Патруль:** ломаная в слое «Патрули». Двигайте узлы инструментом «Правка многоугольников» (`E`).
  Новый маршрут: инструмент «Ломаная», щелчки по точкам, двойной щелчок — конец.
- **Зона:** многоугольник в слое «Зоны». Двигайте вершины (`E`). Маленькая зона внутри большой рисуется поверх неё.

## 7. Сохранить и проверить

`Ctrl+S` сохраняет регион. Затем:

```
npx tsx tools/tiled/validate.ts
```

Проверка сообщит, если:
- закрыт проход к городу, форту, поселению, камню телепорта, мосту, входу в данж или арене босса;
- объект стоит в воде, лаве или стене;
- моб стоит в непроходимом месте;
- `id` повторяются.

Сводка по прочитанной карте: `npx tsx tools/tiled/import.ts`.

## 8. Что пока НЕ применяется в игру

- **Ничего из правок в Tiled.** Мир в игре по-прежнему строит `generateMap`. Повторный экспорт перезаписывает `tools/out/tiled/`.
  Если правки нужны, сохраните копию папки.
- NPC, патрули и телепорты пока только для просмотра: игра берёт их из кода и `data/`.
- Проходимость сейчас хранится слоем как есть. После переключения её будет пересчитывать импорт (из земли и объектов).
- Новые виды объектов (новые картинки) делает генератор арта. После этого они появятся в наборе «Объекты» при следующем экспорте.
- Интерьеры, подземелье, рейд и арены PvP — отдельные карты, в Tiled их пока нет.
