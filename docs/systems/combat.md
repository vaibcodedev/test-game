# Бой, контроль, управление и прицел

**Когда читать:** перед правкой контроля (CC), DR, умений с прицелом, выбора цели мышью, клавиш, панелей, поведения мобов в бою.
**Главное:** ЛКМ по врагу — только выбор, атака — ПКМ/T/умение; схема по умолчанию «Экшен», прицел «С превью». Превью умения считается теми же функциями, что и сервер (shared/skillShape.ts). Хитбокс — по силуэту кадра (client/src/game/hit.ts, тест tests/pick.ts). Все числа CC — в data/cc.json, в коде только механика. Сервер авторитарен, клиент шлёт намерения.

## Решения владельца
- **2026-10-19.** ЛКМ по врагу — только выбор (как WoW); опция «ЛКМ атакует» по умолчанию выкл. Атака — ПКМ по врагу, T, атакующее умение. Схема по умолчанию у новых — «Экшен», «Классика» в настройках; старым при первом входе — выбор схемы (по умолчанию «Экшен»). Прицел по умолчанию «С превью»: пока клавиша зажата — кольцо дальности и область/линия, каст при отпускании; «Быстрый» и «С подтверждением» — в настройках.
- **2026-10-21.** Превью — сочетание: призрак эффекта (золотой — каст пройдёт, серый — позже, красный — сервер откажет) для стены огня, знамени, капкана, призывов; точный контур — для облаков и дождей; кольцо дальности с дальномером и траектория до стены — у всех; подсветка задеваемых.
- **2026-10-21.** Выбор цели — пакет «как в WoW»: зона по силуэту, приоритет при наложении, магнит, клик по нику и полоске HP, подсветка кольцом, Tab только по экрану, Space — атака цели в «Экшене», след 120 мс за бегущими.
- **2026-10-21.** Метеор, «Круг света», «Чумной туман», «Град стрел» — только в прямой видимости; отказ виден красным заранее. `cl_radiance` режут только стены (не вода и деревья).
- **2026-10-21.** Умение на цель без точного наведения уходит в выбранную цель; враг у курсора в 80 px — только если цели нет.
- **2026-10-24.** Мешки и узлы добычи, а также все NPC берут обе кнопки мыши в обоих пресетах (подойти и взять/поговорить); курсор-перчатка `take`, мягкое свечение (GameScene.takeGlow).
- **2026-10-30.** «Очищение» (`cl_cleanse`) снимает и яды Ассасина (`clearPoisons`, B21), и «Пиявку» Кровотворца (B20). «Жертва крови» (`bw_sacrifice`) стоит только здоровья (cost % от макс. здоровья), без маны — на себя работает и при 0 маны (B22).

## Контроль (CC)
| Тип | Нельзя | Можно | Ломается | Флаг |
|---|---|---|---|---|
| stun | двигаться, атаковать, умения (кроме `usableInStun`) | — | нет | BUFF_STUN |
| root | двигаться | атака, умения; рывки — только с `breaksRoot` | нет | BUFF_ROOT |
| slow | — (скорость −pct, потолок `maxSlowPct` 70) | всё | нет | BUFF_SLOW + `slowPct` в схеме |
| silence | умения (кроме `usableInSilence`) | автоатака, бег | нет | BUFF_SILENCE 2048 |
| fear | управление: сервер ведёт прочь от источника | — | урон ≥ `fear.breakHp`·maxHp (DoT с весом `fear.dotWeight`) | BUFF_FEAR 4096 |

- Стан и страх прерывают каст (`castUntil`, `mountCast`, замах моба `windUntil`); безмолвие — только каст умений, мобу-кастеру блок `silenceLockMs`.
- Длительность: `ms × (1−ccReduce) × pvp.ccMult × DR`, потолок `maxMs[тип]` (по 4000). Цепочки разных типов ограничены `chain` (потолок полного контроля, потом краткий иммунитет).
- **DR** (только герой→герой и питомец героя→герой), категории `stun`, `root` (корни, вмерзание), `fear`, `silence`, `slow` — свой счётчик у каждой. Жёсткие `[1, .5, .25, 0]`, сброс `drMs` 18000 после последнего наложения. Замедления — мягко `[1, .75, .5, .5]` по сроку. Притяжения и отбрасывания — без DR. k=0 — «Иммунитет» и аура `dr_<cat>` (в рамке цели в PvP).
- **Мобы:** без DR, `weak.cc` — множитель при наложении; элиты `eliteMult` 0.7; контроль мобов по героям — потолок `mobMaxMs`.
- **Боссы** (`def.boss`, рейд, зонные), правило `cc.boss`: стан и корни → замедление `convSlow` %, страх не ложится, безмолвие только сбивает каст, сила замедления ×`slowMult` 0.5. Поштучные «босса — замедление» в умениях не нужны.

### Где в коде
- `server/src/game/effects.ts` — одна точка `applyCc(w, by, a, kind, ms, pct?)` + обёртки `applyStun/Root/Slow/Silence/Fear`, DR-таблица, правило боссов, `breakFear`, `cleanseCc`.
- `Player.ts`, `Mob.ts` — `stunUntil`, `rootUntil`, `slowPct/slowUntil`, `silenceUntil`, `fearUntil`, `fearFrom`, `frozenUntil`.
- `World.ts` — `canMove`, шаг страха, запрет автоатаки под страхом, прерывание кастов, `hit()` → `breakFear`.
- `skills.ts castSkillInner` — проверки безмолвия/страха, флаги умения `usableInStun/usableInSilence/breaksRoot`.
- `auras.ts` + `data/auras.json` — значки в рамке; `data/aura-fx.json debuffs` — эффекты над головой; клиент `UnitView.ts`, `auraFx.ts`, предсказание скорости по `slowPct`.
- `data/cc.json`: `maxMs`, `maxSlowPct`, `dr`, `drMs`, `slowDr`, `drCat`, `chain`, `fear`, `boss`, `eliteMult`, `silenceLockMs`, `mobMaxMs`, `skills.<id>` (CC-поля умений: `usableInStun`, `usableInSilence`, `breaksRoot`, `cleanse`, `immune`); код читает через `ccOf(id, rank)`. `pvp.ccMult` — `data/balance.json`.
- Тест: `tests/cc.ts` (DR и сброс, потолки, боссы, страх от урона, безмолвие, стан рвёт каст).

### Стиль контроля классов
| Класс | Стиль | Выход |
|---|---|---|
| Храмовник | стан, прерывание (`charge`, `tp_shield_bash` + безмолвие, `quake`) | `tp_divine` в стане, `charge` снимает корни, `unbending` |
| Клирик | безмолвие (`cl_radiance`), страх от разбитого `holyshield` | `cl_cleanse` в стане |
| Егерь | кайт: замедления до 70 %, капканы | `roll`, `hr_trickroll` |
| Боевой маг | лёд: `frostnova` — корни, потом замедление; `mg_bolt` — безмолвие | `blink` в стане и корнях |
| Ассасин | стан-лок из тени (`as_cheap` ≤4 с), кик `shadowstep` | `stealth`, `as_smoke`, `as_escape` |
| Рыцарь смерти | притяжение + лёд, `dk_iron_chains` | `dk_anti_magic`, `dk_icebound` |
| Кровотворец | страх кровью (`bw_blood_burst`) | `bw_sacrifice` под безмолвием |
| Тёмный следопыт | безмолвие (`dr_raven`) + корни (`dr_snare`) | `dr_shadowmeld` |
| Чернокнижник | страх (`wl_hex`), корни (`wl_skeletons`) | `wl_meta` — иммунитет к страху и корням |
| Потрошитель | догон ближника (`rv_hamstring`, `rv_leap`, `rv_throw`) | `rv_frenzy` — иммунитет к замедлению |

Риски баланса держать на виду: кайт мага и Егеря против ближника (у ближников обязательны рывок и снятие корней), лекари под безмолвием, Агония Чернокнижника ломает свой страх (`dotWeight` 0.5, `breakHp` 0.1), боты арены и симулятор должны уметь выходить из CC. Проверка — `tools/balance/sim.ts --only pvp,pvproles,pve,boss`.

## Управление
- Клавиши: `client/src/game/keybinds.ts` — действия → до 2 сочетаний или кнопка мыши, пресеты «Классика» и «Экшен», `localStorage keybinds:v1` (хранятся только отличия). Модификаторы совпадают точно (Shift+1 ≠ 1), кроме движения. Esc зашит. F1–F5 и Tab — `preventDefault`. Запрещены Ctrl+W/T/N/Tab, F11, F12, Alt+F4. Хоткеи молчат только при фокусе в текстовом поле (`isTextField`). Справка и подписи строятся из раскладки.
- **«Экшен» (по умолчанию):** ПКМ по земле — путь (удержание — за курсором), ПКМ по врагу — атака с подходом, по NPC/мешку/узлу — взаимодействие; WASD выкл. Умения Q W E R A S D F T, предметы 1–3, автобег V, G — взаимодействие, Tab — цель, Пробел — атака цели, X/Z — маунт/питомец.
- **«Классика»:** WASD/стрелки, клик-путь, удержание мыши > 200 мс — за курсором; 1–9, 0, Q, E (Q/E — зелья); R — автобег; Shift+F — следовать; F/Space — взаимодействие; Alt — на себя; F1–F5 — группа.
- Выбор не атакует и не двигает. Клик по земле и WASD цель не снимают (только преследование). Цель снимают Esc, смерть, невидимость, > 900 px. После шага герой стоит; автоатака продолжается, если цель в дальности. Опции «Преследовать цель», «Подходить к цели» (каст вне дальности: сервер помнит 4 с и подводит).
- Каналы и касты (гимн, воскрешение, телепорт 3 с, маунт 2 с) рвёт движение; сервер шлёт `cast {ms,name}`, клиент не предсказывает шаг под `castUntil`, `frozenUntil`, станом, корнями.
- GCD 0,75 с (`data/balance.json gcd`), `offGcd` у рывков и защит. Очередь: нажатие ≤ 400 мс до готовности исполняется (одно умение, новое заменяет). Удержание клавиши — повтор раз в 150 мс.
- Панели: `shared/hotbar.ts` — 2 × 12 слотов (`{s}` умение, `{i}` предмет по `base`, `{a}` действие); хранятся в `PlayerSave.bars`, сообщения `bars:set`, `bars:swap`, `use:base`. Автостановка изученного умения. UI — `client/src/ui/hotbar.ts` (DnD из K и I, замок, Shift-перетаскивание). Настройки — `client/src/ui/controls.ts`.
- Взаимодействие F/Space/G: объект под курсором → ближайший в 110 px (мешок → узел → NPC → камень) → в 110–300 px подойти. Подсказка «[F] Поговорить: …».
- Ошибки — строка над панелью с тем, чего не хватает («Слишком далеко: ещё 3 кл.», «Не хватает маны: 12 из 20»); `toast.code` (`target|range|los|mana|cd|learn`).
- Тачпад: «Крупные цели» — допуск и магнит ×2; колесо — зум 2–3 (`zoom:v1`).
- Протокол: `target` — только выбор; `attack`, `follow`, `cancel`, `use:base`, `bars:*` от клиента; `cast` от сервера.

## Выбор цели мышью
- Попадание — чистая функция `client/src/game/hit.ts` (`UnitView.hitTest`): прямоугольник силуэта ±0,42 кадра, 0,9 кадра над ногами, 1/16 под (питомцы ×0,8); всадник — кадр героя ∪ непрозрачная часть маунта. Вторая зона — плашка (ник, титул, HP, запас 2 px). След 120 мс за бегущим (`TRAIL_MS`). Допуск 12 px экрана; магнит 40 px — только у ЛКМ в «Экшене» (только выбирает).
- Порядок при наложении (`PickBest`, один для клика, подсветки, адресата умения): точное попадание → передний по глубине (y ног; плашки над телами) → текущая цель → ближе центр. Допуск мелкого не отбирает клик у тела крупного. Свой герой и питомцы — только по телу.
- Порядок типов (`castResolve.pickOrder`): прицел → враг точно → мешок, узел, NPC → герой чужой фракции в нейтральном городе (только по телу) → меню союзника → союзник точно → враг магнитом → земля.
- Наведение пересчитывается каждый кадр. Подсветка — бледное кольцо (P.foe/P.ally), ник и HP; курсор-меч — кого атакует ПКМ; во время прицела — стрелка.
- Tab: только враги на экране (`cameras.main.worldView`) с видимостью; сначала бьющие меня, потом ближние (`castResolve.tabOrder`); список замораживается на 2 с; Shift+Tab — назад.
- Адресат умения: юнит под курсором (тот же pick) → выбранная цель → если цели нет — враг у курсора в 80 px (`PICK_NEAR`) → союзные — на себя.

## Превью умений
- Геометрия превью = серверная: `shared/skillShape.ts` (форма и размеры по рангу и пассивкам, «куда ляжет» и «кого заденет», `reachable`, луч до стены, `behindSpot`), поля в `data/skills_aim.json`: `aim` (`unit|ground|dir|dash|self`), `shape` (circle, wall, bolt, band, fan, cone, dash, nova, leap, behind, pull), `los`, `oor` (clamp|walk|deny), `r`, `w`, `inner`, `ray`, `summon`, `trap` и др. (описание — `_doc` файла).
- Круги — настоящие круги (сервер меряет `Math.hypot`), не эллипсы. Красный — ровно там, где откажет сервер. В «skill» уходят угол и вектор, точка ground прижимается с допуском.
- Вид: призрак (setTintFill, шахматка 50 %, контур 1 px), облака — контур с дизерингом 25 %, dir — полоса до препятствия, дальше серый пунктир и «×», рывки — путь и силуэт, кольцо — пиксельный пунктир. Без Glow, ADD и поворота спрайтов. Клик по слоту ground/dash — режим подтверждения.
- Тесты: `tests/skill-shape.ts` (превью = сервер: точка, форма, задетые, решение), `tests/cast-resolve.ts`, `tests/pick.ts`, `tests/controls.ts`, `tests/keybinds.ts`, `tests/hotbar.ts`; снимки `tests/aim-screens.ts`, `hover-screens.ts`, `aim-modes-screens.ts`.
