# Всё в конфигах: аудит, план и редактор

Документ для владельца игры, простым языком. Цель, которую вы поставили: «через конфиг должна быть возможность менять почти всё, что у нас есть» — вплоть до реплик боссов, частоты событий, шансов, цен и ассортимента. Исключение — только техническая начинка (порты, протокол, слои отрисовки).

Как читать статусы: **в конфиге** — уже правится в редакторе; **перенесено (партия 1)** — перенесено в `data/gameplay.json` и работает так же, как раньше; **после** — перенесём позже (файл сейчас правит другой агент или значение связано с генерацией карты); **не выносим** — см. раздел 3.

Редактор запускается командой `npm run editor` (адрес по умолчанию `http://localhost:5300`, порт меняется переменной `EDITOR_PORT`). Новое поле в любом `data/*.json` редактор показывает сам; без описания в схеме оно получает объяснение по имени поля, а описание из `_doc`-комментариев файла показывается над полем.

## 3. Что нельзя или не стоит выносить

| Что | Почему |
|---|---|
| Порты, адреса, коды закрытия соединения (`LOGOUT_CODE`, `KICK_CODE`), сетевые таймауты, версия протокола | Техническая начинка: ошибка ломает соединение у всех. |
| Слои отрисовки, порядок рисования, `FRONT` у эффектов, размеры чанков и тайлов (`CHUNK`, `COLS`, `TERRAIN_COUNT`, `MAP_VERSION`) | Меняет внутреннее устройство картинки, а не игру; ошибка даёт визуальный мусор. |
| Размер карты и сид (`MAP_W`, `MAP_H`, `MAP_SEED`) | Сломает все сохранения и стыки зон. Меняется только отдельной задачей с перегенерацией. |
| Данные безопасности: правила имён, лимиты сообщений в `server.json` | Менять можно осознанно, но редактор не должен позволять «выключить» защиту (границы в схеме). |
| Формулы как код (броня → урон, лучшая цель, прицеливание, интерполяция кривых) | Это логика, а не числа. Но **коэффициенты** этих формул выносятся (опыт, ловкость → уклонение, кривые мобов уже вынесены). |
| Протокол сообщений между клиентом и сервером | Должен совпадать у клиента и сервера. |
| Идентификаторы (id мобов, предметов, умений, классов) | На них ссылаются сохранения. Менять нельзя; редактор не позволяет переименовать id без проверки «где используется». |
| Значения, привязанные к генерации карты (пояс города, размеры поселений) | Влияют на раскладку и версию карты; меняются вместе с перегенерацией. |

## 4. Что предлагаю добавить в редактор

| Возможность | Что даёт |
|---|---|
| Применение на лету, без перезапуска сервера разработки | Меняете число — через секунду видите в игре. Хотфиксы без остановки. |
| История правок и откат к любой версии | Видно, кто и что менял; ошибку можно отменить кнопкой. Сейчас откат — только к последнему коммиту. |
| Массовые правки в таблицах | «Все мобы 30–40 уровня: здоровье +10 %», «все цены маунтов ×1,2». |
| Симулятор баланса перед сохранением | Перед записью показывает: за сколько секунд убивается моб, как меняется длительность дуэли. Защита от «поломал баланс». |
