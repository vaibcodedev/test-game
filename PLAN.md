# Пепельный Предел — план разработки

2D MMORPG в браузере и на десктопе. Клиент на Phaser 3, авторитарный сервер на Colyseus, прогресс хранится в SQLite. Устройство кода — ARCHITECTURE.md, следующие этапы — BACKLOG.md.

### Решения пользователя (действуют дальше)

- Умения: у каждого класса ровно 9 активных и 11 пассивных (проверяет tests/factions.ts).
- Предметы: фракция — только стиль вида (поле fac), характеристики и доступность одинаковы для обеих фракций.
- Заточка: в интерфейсе только значок +N на ячейке (без обводки и заливки); на герое — приглушённый контур своей вещи (docs/gear-visuals.md).
- Добыча — по уровню источника: боссы, элиты, арена, легендарки.
- Управление: ЛКМ по врагу — только выбор цели, схема по умолчанию «Экшен», прицел «С превью» (docs/controls.md).
- Арена: бои с ботами дают рейтинг ×0,5 (BOT_RATING_MULT) и пишутся в историю с пометкой «бот».

### Порядок работы с агентами

- Параллельно — только задачи с непересекающимися файлами (2–4 агента), остальные по очереди.
- Агентам нельзя git stash, git checkout -- <файл>, git reset, git restore (общее рабочее дерево); старую версию смотреть через git show HEAD:<файл> или git worktree. Коммитит координатор.
