# Пепельный Предел

2D MMORPG в браузере и на десктопе: клиент Phaser 3, авторитарный сервер Node.js + Colyseus 0.16, прогресс в SQLite (`node:sqlite`). Две фракции (Сольгард и Умбрат), 10 классов, уровни до 100, арена, рейд, война фракций. Графика — оригинальный пиксель-арт, его рисует генератор `tools/gen`.

**Документация — [docs/README.md](docs/README.md).** Правила для Claude — [CLAUDE.md](CLAUDE.md), план — [docs/plan/plan.md](docs/plan/plan.md).

## Установка и запуск

Нужен **Node.js 22.13 или новее**: используется встроенный модуль `node:sqlite`, поэтому собирать нативные зависимости не нужно.

```bash
npm install
npm run dev
```

`npm run dev` одной командой генерирует ассеты и запускает сервер (порт 2567) и клиент (порт 5190). Откройте http://localhost:5190 и нажмите «Создать аккаунт» (или войдите в существующий).

**Аккаунты.** На аккаунте до 6 героев: экран выбора показывает спрайт, снаряжение, класс, уровень и локацию; кнопки «Играть», «Создать», «Удалить» (подтверждение вводом имени), Esc — шаг назад. При создании — уникальное имя (3–16 букв, кириллица или латиница, цифры), класс и оттенок внешности. Одновременно в мире — один герой аккаунта. У банкира есть вкладка «Общий склад», общая для всех героев аккаунта. Герои, созданные до аккаунтов, перенесены автоматически: логин — имя героя, пароль прежний (перед переносом сервер делает копию `server/data/game.backup-<дата>.sqlite`). Вход — HTTP `POST /api/login` → токен сессии, затем вход в комнату с `{ token, character }`; 5 неверных паролей подряд — пауза 5 минут.

**Выход.** Меню (Esc) → «Сменить персонажа» или «Выйти из аккаунта». Вне боя выход мгновенный, в бою — отсчёт 10 с, который прерывается полученным уроном. Обмен отменяется, очередь арены и группа покидаются, питомец и маунт убираются; страница не перезагружается.

Чтобы проверить мультиплеер, откройте вторую вкладку и войдите другим героем.

Режим production, когда сервер сам раздаёт собранный клиент:

```bash
npm start            # сборка клиента в dist/ и запуск сервера
# откройте http://localhost:2567
```

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `2567` | порт HTTP и WebSocket сервера |
| `DB_PATH` | `server/data/game.sqlite` | файл базы SQLite |
| `VITE_SERVER_URL` | `ws://<хост>:2567` в dev, тот же адрес в production | адрес сервера для клиента |

## Десктоп-приложение

Игра собирается в программу для Windows на Electron. При запуске открывается лаунчер:

- **«Играть»** — запускает встроенный сервер на этом компьютере и открывает игру. Интернет не нужен. Сервер работает отдельным процессом, слушает только `127.0.0.1` на свободном порту (сначала 47821), поэтому брандмауэр не спрашивает разрешения.
- **«Адрес сервера» и «Подключиться»** — вход на сетевой сервер, например на сервер проекта: `http://localhost:2567` (на этом же компьютере после `npm start`) или `192.168.1.20:2567` (в локальной сети). Схему можно не писать. Адрес запоминается.
- **«Перенести мой аккаунт из базы проекта»** — см. ниже.
- Внизу показаны версия и ссылка на папку журналов. Если сервер не поднялся, лаунчер показывает причину и путь к журналу.

Окно игры открывается размером 1280×800 (минимум 1024×640) и запоминает размер и положение. F11 включает полный экран. Tab, F1–F5 и Alt приложение не перехватывает, они работают в игре. Можно запустить только одну копию: повторный запуск выводит на передний план уже открытое окно. При выходе сервер сохраняет героев, закрывает базу и завершается сам.

### Сборка

```bash
npm install
npm run desktop:build      # клиент + бандлы + electron-builder → release/
```

В папке `release/` появятся:

- `AshenReach-Setup-<версия>.exe` — установщик: можно выбрать папку, создаются ярлыки на рабочем столе и в меню «Пуск»;
- `AshenReach-Portable-<версия>.exe` — версия без установки, один файл;
- `win-unpacked/` — распакованная программа.

Другие команды:

```bash
npm run desktop:dev        # запуск без упаковки (Ctrl+Shift+I — DevTools)
npm run desktop:smoke      # проверка: сам жмёт «Играть», делает снимок release/smoke.png и выходит
npm run desktop:typecheck  # TypeScript десктоп-части
npm run desktop:icon       # перерисовать иконку desktop/build/icon.{png,ico}
```

Собранную программу можно проверить так же: `$env:SMOKE=1; .\release\win-unpacked\AshenReach.exe` (PowerShell). Снимок сохранится рядом с exe как `smoke.png`. Если задать `SMOKE_CONNECT=http://localhost:2567`, проверка вместо «Играть» подключится к этому серверу. В режиме проверки используется временная папка `%TEMP%\AshenReach-smoke`, настоящие сохранения не затрагиваются.

### Где лежат данные

Всё хранится в `%APPDATA%\AshenReach` (обычно `C:\Users\<имя>\AppData\Roaming\AshenReach`):

| Файл | Что это |
|---|---|
| `game.sqlite` (+ `-wal`, `-shm`) | база героев и аккаунтов десктоп-версии |
| `game.sqlite.bak-<дата>` | прежняя база, сохранённая при переносе аккаунта |
| `config.json` | адрес сетевого сервера, порт встроенного сервера, размер и положение окна |
| `logs\main.log`, `logs\server.log` | журналы приложения и встроенного сервера (`*.prev.log` — с прошлого запуска) |

При удалении программы эта папка остаётся, сохранения не пропадают.

### Как перенести аккаунт

У десктоп-версии своя база, отдельная от `server/data/game.sqlite`, на которую работают `npm start` и `npm run dev`. Поэтому герои, созданные в браузере, в десктопе сначала не видны. Есть два варианта:

1. **Играть на сервере проекта.** Запустите `npm start` и в лаунчере введите адрес `http://localhost:2567`.
2. **Перенести базу в десктоп.** Нажмите в лаунчере «Перенести мой аккаунт из базы проекта». Лаунчер ищет `server/data/game.sqlite` в папке проекта: в той, откуда запущен `desktop:dev`, в той, где собиралась программа, и в папках над exe. Если файл не найден, откроется окно выбора файла. Лаунчер копирует базу вместе с `-wal` и `-shm`, проверяет копию и показывает, какие герои в ней есть. После подтверждения он останавливает встроенный сервер, сохраняет текущую базу десктопа как `game.sqlite.bak-<дата>` и ставит на её место копию. Входите прежним логином и паролем.

Перед переносом лучше остановить `npm start`: изменения героев, которые сейчас в игре, могут не успеть попасть в копию (лаунчер об этом предупредит). Чтобы вернуть прежнюю базу десктопа, выберите через ту же кнопку файл `game.sqlite.bak-<дата>` (кнопка «Другой файл…»).

## Проверки

```bash
npm run typecheck    # TypeScript для всего проекта
npm run test:unit    # быстрые тесты без сервера
npm test             # прежняя цепочка, в том числе тесты с сервером (по одному, под замком tools/out/scenario.lock)
npm run db           # таблица героев с аккаунтами (npm run db -- <имя> — подробно)
```

Карта тестов — [docs/process/tests.md](docs/process/tests.md). Тесты поднимают отдельный сервер на порту 2601 с временной базой (`TEST_MODE=1`). Скриншотам нужен Chrome или Edge (`CHROME_PATH`).
