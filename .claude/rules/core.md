# Общие правила (грузятся всегда)

- Перед работой прочитай гайд по теме из таблицы в CLAUDE.md; индекс — docs/README.md.
- Перед проектированием системы, интерфейса, арта или эффекта — WebSearch по 2–4 топовым MMORPG (WoW, Lineage 2, Lost Ark, Black Desert, Aion, Guild Wars 2, Albion; 2D-мир — Warspear Online), лучшие практики, стиль свой, ассеты не копировать; варианты владельцу — с пометкой, откуда идея.
- Агенты не трогают git (add, commit, stash, checkout --, reset, restore); коммитит координатор.
- Прогоны с сервером, Vite и Chrome — строго по одному, под замком tools/out/scenario.lock*; чужой живой замок не удалять; зависший (процесса с PID из файла нет) — удалить после проверки PID.
- `npm run assets` без нужды не запускать (долго); атлас — отдельно tools/gen/atlas.ts.
- Новый контент и числа — в /data, не в коде. Операции с предметами и золотом — атомарной транзакцией.
- Читать только указанные файлы; отчёт агента — до 5 строк; ответы владельцу — по-русски.
- Новое правило из просьбы владельца — сначала сформулировать и спросить одобрение (опросник), после одобрения — в профильный гайд docs/ с датой; новые файлы не плодить.
- Версия игры data/version.json — координатор поднимает patch при каждом обновлении.
